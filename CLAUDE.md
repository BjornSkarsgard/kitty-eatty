# Накорми котиков — инструкции и состояние

Актуализировано 2026-10-30. Основная краткая память проекта и договорённости с Иваном — [AGENTS.md](AGENTS.md). Не использовать прежний план этапов как описание текущей реализации.

## Текущая игра

JavaScript ESM, Phaser 3.90.0, Vite 8.3.4, экран 720×1280. Сортировка видимой верхней серии корма по стеклянным банкам. Собранную банку ест кот, затем появляется джут; кормление не блокирует другие ходы. Победа — все банки собраны или пусты. Есть скрытый корм, лёд, отмены, подсказка, дополнительная банка и 15 ульт. 300 уровней, главы по 20; сложные 5/10/15, кошмарный 20. Звёзд за ходы нет.

Реализованы холл и комнаты, карта, магазин за монеты, опыт кота, жизни, рубежи, подарок дня, сундуки, 20 окрасов и 48 кличек. Индивидуального арта пород пока нет. Реальные платежи и рекламный SDK выключены; тестовые rewarded-показы имитируются. Cordova, SDK площадок, аналитика, серверные аккаунты и публикация в магазинах — будущая интеграция, не готовая часть проекта.

## Работа и стиль

Общение по-русски, кратко. В рамках задачи самостоятельно читать, править и проверять код. Новые зависимости и неоднозначные изменения механик/баланса согласовывать. После рабочего шага делать понятный коммит. Числа держать в CONFIG. Беречь локальный прогресс (сохранение v16).

Любую генерацию сначала показывать Ивану вне проекта. Только после явного одобрения сохранять, подключать и коммитить. Сад второй главы одобрен 2026-10-30. Мягкий объёмный мультяшный стиль Royal Match / Magic Sort, свет сверху слева. Коты из частей, твины Phaser; шерсть не красить setTint. Карта — вид сверху. Цель — 60 FPS на бюджетном Android; полноэкранных тяжёлых эффектов избегать.

`npm run dev` — сервер (обычно 5173; занятый порт приводит к следующему), `npm run build` — только сборка. Проверки механики по задаче: `npm run levels:check`, `node tools/hint-check.mjs`. Симулятор меты пока расходится с CONFIG, не использовать его старые прогнозы для нового баланса. Генерация уровней — отдельное действие, не часть обычной сборки.

Исправления GitHub: воспроизвести, исправить, проверить, коммит Fixes #N, доставка, ответ тестировщику и закрытие после доставки. Отчёты экономики автоматически не закрывать. Push main публикует тестовую игру через GitHub Actions.

## Правила будущей монетизации

Не включать платежи или SDK случайно. Награда rewarded — после досмотра, ошибка не должна блокировать игру. Реальные покупки — через официальные механизмы площадки с проверкой; при собственном эквайринге цены/состав и проверка — на сервере. «Без рекламы» должно отключать межуровневые показы. Старые ограничения: межуровневая не раньше уровня 3 и не чаще раза в 2–3 уровня; фактический график внедрения ещё не реализован и требует согласования.
