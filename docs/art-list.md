# Полный список арта

Всё, что понадобится для игры целиком, по этапам. Правила стиля, перекраски и запросы для ChatGPT — в [art-spec.md](art-spec.md).

Пометки:
- **[П]** — рисуется белым для перекраски игрой (заливка #FFFFFF, тень #C8C8D2, контур #1B1426).
- **[Ц]** — рисуется сразу в цвете.
- **[код]** — рисует сама игра, картинка не нужна.

Все PNG с прозрачным фоном, в `src/assets/`.
