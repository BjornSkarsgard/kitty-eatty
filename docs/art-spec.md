# Арт: стиль и как генерировать в ChatGPT

Полный список всего арта по этапам — в [art-list.md](art-list.md). Здесь — детали для этапа 4.

Все картинки — PNG с **прозрачным фоном**. Кладём в `src/assets/` с точными именами из таблиц. Если файла нет, игра рисует временную фигуру, поэтому можно добавлять по одному.

## Общий стиль (вставлять в начало каждого запроса)

> 2D cartoon game asset, clean vector style, thick dark outline (#1B1426, consistent line width), flat fills, exactly one shadow tone, small white highlight spots, no gradients, no texture, no text, no background (transparent PNG), centered, front view, cute and friendly, mobile casual game.

**Чтобы стиль совпадал:** сгенерируй первую часть (голову), а в следующих запросах прикладывай её картинку и пиши «in exactly the same style as the attached image».

## Коты: части для перекраски

Кота перекрашивает игра, поэтому части тела рисуются **белыми**:
- заливка — чистый белый #FFFFFF;
- тень — один светло-серый тон #C8C8D2;
- контур — тёмный #1B1426.

Игра умножит это на цвет кота: белое станет цветом, серое — тенью того же цвета, контур останется тёмным. Белые пятна (морда, грудка) — **отдельные файлы**, иначе их тоже перекрасит.

| Файл | Что нарисовать | Холст |
|---|---|---|

| `cat_body.png` | Сидящее тело с передними лапками, вид спереди, без головы и хвоста. | 512×512 |
| `cat_tail.png` | Хвост, загнутый вверх, основание внизу слева. | 256×512 |

| `cat_spots_body.png` | Только белое пятно грудки. Положение как на теле: рисовать поверх `cat_body.png`. | 512×512 |
| `cat_eyes_open.png` | Пара глаз, открытые, большие, с бликом. Не перекрашиваются. | 512×256 |

Пример запроса для головы:
> [общий стиль] A cat head with two pointy ears, round shape, no eyes, no mouth, no nose. Fill pure white #FFFFFF, the only shadow tone light grey #C8C8D2, outline #1B1426. Transparent background. 512x512.

## Корм: 10 видов

У каждого цвета свой корм с **узнаваемым силуэтом**, чтобы различать без цвета (для дальтоников). Корм рисуется уже **в своём цвете** (его не перекрашиваем).

| Файл | Корм | Цвет |
|---|---|---|
| `food_0.png` | Котлетка или фрикаделька (круглая) | красный #FF6B6B |
| `food_1.png` | Рыбка | синий #4DABF7 |
| `food_2.png` | Печенье-звёздочка | жёлтый #FFD43B |
| `food_3.png` | Пучок кошачьей мяты | зелёный #69DB7C |
| `food_4.png` | Ромбик желе | фиолетовый #CC5DE8 |
| `food_5.png` | Кусочек лосося | оранжевый #FF922B |
| `food_6.png` | Сердечко-печенье | бирюзовый #3BC9DB |
| `food_7.png` | Пончик-колечко | белый #F8F9FA |
| `food_8.png` | Куриная ножка | коричневый #A47148 |
| `food_9.png` | Креветка | розовый #F783AC |

Холст 256×256, предмет по центру, занимает ~80%. Запрос:
> [общий стиль] A single cat treat: a small fish, main color #4DABF7. Transparent background. 256x256.

## Что рисует сама игра (картинки не нужны)

- Банки для корма: стекло, блики, подставка. Это простая геометрия, и она тянется под вместимость 4 или 5.
- Слои корма в банке: цветная полоса с иконкой корма из `food_N.png`.
- Крошки, сердечки, искры при кормлении.

## После генерации

1. Проверь, что фон действительно прозрачный, а не белый или «шахматка».
2. Обрежь лишние поля, если они огромные. Точный размер не важен: смещения и масштаб частей я подгоню в `src/config.js`.
3. Положи в `src/assets/` и напиши мне, я подключу и подгоню.
