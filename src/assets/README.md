# Ассеты

Сверено 2026-10-30. Фактический реестр картинок и очередь — [docs/art-list.md](../../docs/art-list.md), требования — [art-spec.md](../../docs/art-spec.md). Звук и источники — [sound-spec.md](../../docs/sound-spec.md), [audio/SOURCES.txt](audio/SOURCES.txt).

Новые генерации сначала показать Ивану вне проекта; только после явного одобрения сохранять сюда и подключать. Наличие старого файла само по себе не подтверждает одобрение новой версии. Фон сада map_bg_2.jpg одобрен 2026-10-30.

`src/assets.js` автоматически собирает PNG, WebP, JPG, SVG, MP3 и OGG, кроме `src/assets/загрузки/`. Ключ — имя без расширения: одинаковые имена в разных каталогах/форматах конфликтуют. WOFF2 подключаются отдельно через `src/fonts.js`. Отсутствующий необязательный арт обычно заменяется фигурой, отсутствующий звук молчит; это не гарантия безопасного удаления произвольного используемого файла.

Исходники — в `art-src/` (игнорируется Git). Конфиг, CatView и `cat-layout.json` определяют сборку и размеры на экране. Не перегенерировать готовый арт по старым промптам автоматически.
